# Dark Mode Chat App Template

This is a front-end template for a dark mode chat application, built using HTML, CSS, and vanilla JavaScript. It matches the design shown in your reference image.

## How to use this project

1. **Unzip the files:** Extract all files from this ZIP archive into a folder on your computer.
2. **Local Preview:** Simply double-click `index.html` to open it in your web browser. You can type messages in the input box and press "Enter" to see the chat in action!

## How to Upload to a GitHub Repository

To share this code or host it online for free using GitHub Pages, follow these steps:

### Prerequisites:
- You need a free account on [GitHub](https://github.com/).

### Step 1: Create a new repository
1. Log in to GitHub.
2. In the top-right corner, click the **+** dropdown menu, and select **New repository**.
3. Name your repository (e.g., `dark-mode-chat`).
4. Choose whether to make it Public or Private (Public is required if you want to use GitHub Pages for free).
5. Do **NOT** check "Add a README file" (since this ZIP already includes one).
6. Click **Create repository**.

### Step 2: Upload your files
1. On your new repository's page, look for the section that says "...or create a new repository on the command line" and right below it, click the link that says **uploading an existing file**.
2. Drag and drop **all the extracted files** (`index.html`, `style.css`, `script.js`, and `README.md`) from your computer into the box on the GitHub page.
3. Once the files finish uploading, scroll down to the "Commit changes" box.
4. Type a short description like "Initial commit with chat template".
5. Click the green **Commit changes** button.

### Step 3: Publish with GitHub Pages (Optional but recommended)
Want a live link to share with friends?
1. In your GitHub repository, click on the **Settings** tab.
2. On the left sidebar, click on **Pages**.
3. Under the **Build and deployment** section, look for the **Branch** dropdown.
4. Change it from `None` to `main` (or `master`).
5. Click **Save**.
6. Wait a minute or two, and GitHub will provide a live URL (e.g., `https://yourusername.github.io/dark-mode-chat/`) where you can view your working app online!
